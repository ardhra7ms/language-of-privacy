# Language of Privacy

An interactive exploration of what the word **control** promises in privacy
products, and how that promise differs from effective power over the data
lifecycle.

The site separates two dimensions that privacy interfaces often collapse:

- effective power to know, stop, correct, delete, contest, and leave;
- privacy work placed on the person.

It also provides a nine-part framework for testing whether a privacy control is
substantive, partial, or absent.

## Sources

The model draws on work about privacy self-management, responsibilization, data
sovereignty, and the distinct rights described in GDPR Articles 15-22. Full
references and source links appear on the site.

## Run locally

Open `index.html` directly in a browser, or serve this directory with:

```sh
python3 -m http.server 8000
```
